# Array Tasks

This folder contains Programming Fundamentals (PF Theory) tasks based on Arrays using C++.

## 📚 Description

These tasks are designed to develop an understanding of arrays and their implementation in C++. They cover basic array operations and help improve programming logic and problem-solving skills.

## 🎯 Objective

The main objective of these tasks is to understand how arrays are declared, initialized, accessed, and processed in C++.

## 📌 Concepts Covered

* Array Declaration
* Array Initialization
* Accessing Array Elements
* Traversing Arrays
* One-Dimensional Arrays
* Taking Array Input
* Displaying Array Elements
* Basic Array Operations
* Loops with Arrays
* Problem Solving using Arrays

## 🛠️ Programming Language

* C++

## 📂 Tasks

This folder contains multiple Programming Fundamentals tasks related to Arrays.

Each task demonstrates a different concept or operation involving arrays.

## ▶️ How to Run

1. Open the C++ source file.
2. Compile the program using a C++ compiler.
3. Run the program.
4. Enter the required input.
5. View the output.
